# Qarjy — 15-апта: тестілеу, хостинг және қорғау

## Жоба мүмкіндіктері
- Тіркелу, жүйеге кіру және шығу.
- Жеке қаржылық операцияларды қосу, көру, өңдеу және жою (CRUD).
- Операцияларды іздеу, санат/күн бойынша сүзу, сұрыптау және беттерге бөлу.
- Профильдегі аты-жөні мен email-ді өзгерту.
- PDO prepared statements, пароль хэші, HTML escaping және CSRF тексерістері.

## Локалды іске қосу
1. `Qarjy_15_week_PHP` бумасын `C:\xampp\htdocs\` ішіне көшіріңіз.
2. XAMPP-та Apache және MySQL қосыңыз.
3. `includes/db.php` файлы XAMPP-тағы MySQL 3307 портына бапталғанын тексеріңіз.
4. Егер `qarjy_db` дерекқоры бұрыннан бар болса, оны қайта құрмаңыз. Жаңа ортада `database/qarjy_db.sql` файлын phpMyAdmin арқылы импорттаңыз.
5. `http://localhost/Qarjy_15_week_PHP/login.php` адресін ашыңыз.

Қауіпсіздік үшін орнату скрипттері (`setup_database.php`, `setup_week12.php`) бұл финалдық бумадан алынып тасталды. Дерекқорды SQL файлы арқылы импорттаңыз.

## Хостингке орналастыру
Бұл жоба PHP + MySQL талап етеді. Хостингке жариялау үшін аккаунт ашып, hosting провайдер берген мәліметтер қажет. Бұл пакет өздігінен интернетке жарияланбайды.

1. PHP және MySQL қолдайтын хостинг таңдаңыз; PHP нұсқасы мен PDO MySQL кеңейтімі қосулы екенін тексеріңіз.
2. Хостинг панелінен MySQL дерекқоры мен қолданушысын жасаңыз.
3. `database/qarjy_db.sql` файлын хостингтің phpMyAdmin жүйесіне импорттаңыз.
4. `includes/db.php` ішіндегі `$host`, `$port`, `$dbname`, `$username`, `$password` мәндерін хостинг берген нақты деректермен ауыстырыңыз. Көп хостингте порт әдепкі болады; провайдер берген мәнді қолданыңыз. `root` және бос парольді хостингке қолданбаңыз.
5. Жоба файлдарын доменнің `public_html` бумасына жүктеңіз.
6. HTTPS қосыңыз, сайтты ашып тіркелу/кіру/CRUD/іздеу/профильді тексеріңіз.
7. Қате туралы толық мәліметті экранға шығармаңыз; сервер логын пайдаланыңыз.

Хостинг аккаунтына кіру, файлдарды жүктеу және доменді іске қосу пайдаланушының хостинг панеліндегі әрекетін талап етеді. Құпиясөздерді ешкімге жібермеңіз.
