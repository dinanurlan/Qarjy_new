# Qarjy — 13-апта: Мәліметтермен жұмыс

12-аптадағы Qarjy жобасының жалғасы. Тіркелу, кіру және CRUD функциялары сақталған. Дерекқор құрылымын өзгертудің қажеті жоқ.

## 13-апта функциялары
- **Іздеу:** операция атауы, санаты немесе әмияны бойынша іздеу.
- **Сүзу:** санат, бастапқы күн және соңғы күн бойынша.
- **Сұрыптау:** күні, сомасы немесе атауы бойынша.
- **Пагинация:** бір бетте 5 операция көрсетіледі; келесі/алдыңғы бетке өтуге болады.

## Орнату
1. ZIP файлын ашыңыз. `Qarjy_13_week_PHP` папкасын `C:\xampp\htdocs\` ішіне көшіріңіз.
2. XAMPP-та Apache және MySQL (порт 3307) қосыңыз.
3. `http://localhost/Qarjy_13_week_PHP/login.php` адресін ашыңыз.
4. 11/12-аптада қолданған аккаунтпен кіріңіз.
5. Dashboard-та іздеу, санат/күн сүзгісі және сұрыптауды қолданыңыз. Кемінде 6 операция қоссаңыз, пагинацияны тексеруге болады.

## Техникалық түсініктеме
Сүзгілер серверде SQL WHERE шарттары арқылы орындалады. Барлық пайдаланушы енгізген мәндер PDO prepared statements арқылы беріледі. Сұрыптау бағандары рұқсат етілген тізімнен ғана таңдалады. LIMIT және OFFSET пагинация үшін қолданылады. Қолданыстағы `qarjy_db` дерекқоры мен `transactions` кестесі өзгертілмейді.
